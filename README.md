# 🎬 Netflix Login Page Clone

A responsive and visually appealing clone of the Netflix login page, built using HTML and CSS. This project serves as a practice exercise to replicate a well-known user interface, enhancing skills in front-end web development.

## 🔍 Overview

This project replicates the Netflix login page's design, focusing on layout, styling, and responsiveness. It includes:

- A header with the Netflix logo.
- A login form with fields for email and password.
- A "Sign In" button.
- Additional options like "Remember me" and "Need help?" links.
- A footer with relevant links and information.

## 🚀 Getting Started

To view the login page locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/naqeebansari2004/Netflix-login-page.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd Netflix-login-page
   ```
3. **Open `index.html` in your preferred web browser**.
